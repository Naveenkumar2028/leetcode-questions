# Contributing to the LeetCode Practice Repository

This repository is a record of problem-solving practice. Each solution should be easy to review, run, and learn from.

## Add a solution

1. Create a folder using the LeetCode slug, for example `0206-reverse-linked-list/`.
2. Keep the solution file name descriptive, such as `solution.py` or `solution.sql`.
3. Include the problem link and a short explanation when the platform does not generate one automatically.
4. State the expected time and space complexity.
5. Test at least one normal case and one edge case before committing.

## Review checklist

- Does the solution handle empty input, a single element, or boundary values where applicable?
- Is the chosen data structure or algorithm explained in one or two sentences?
- Are variable names clear enough to follow without extra comments?
- Does the implementation match the language conventions used in the repository?
- Is the commit message specific, for example `add 0206 reverse linked list solution`?

Keeping this checklist close to the code helps turn each accepted answer into reusable interview preparation material.
